Authentication APIs
Login
POST /api/auth/login

Request

{
    "username": "admin",
    "password": "password"
}

Response

{
    "success": true,
    "token": "jwt_token",
    "user": {
        "id": 1,
        "username": "admin",
        "full_name": "System Administrator",
        "role": "ADMIN"
    }
}

POST /api/auth/logout

Response

{
    "success": true,
    "message": "Logged out successfully"
}

Task APIs
Get Task List
GET /api/tasks

Query Parameters

?page=1
&limit=20

&project_id=1
&status_id=3
&platform_id=2
&task_type_id=1
&task_source_id=4
&assigned_to=1

&date_from=2026-06-01
&date_to=2026-06-30

&search=deployment

Response

{
    "total": 250,
    "page": 1,
    "records": []
}

Create Task
POST /api/tasks

Request

{
    "task_details": "Deploy ACS Build",

    "project_id": 1,

    "task_source_id": 4,

    "assigned_to": 1,

    "task_status_id": 1,

    "task_type_id": 2,

    "platform_id": 1,

    "jira_logged": "NO",

    "work_description": "Need to deploy latest build",

    "remarks": ""
}

Response

{
    "success": true,
    "task_id": 125
}
